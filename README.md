# homebrew-tap

Personal Homebrew tap for [sven-s](https://github.com/sven-s).

## Casks

| Name | Description |
| ---- | ----------- |
| [clipbridge](https://github.com/sven-s/clipbridge) | Cross-machine clipboard relay for corporate RDP |

## Install

```bash
brew install --cask sven-s/tap/clipbridge
```

The tap is auto-detected from the `sven-s/tap` prefix — no separate `brew tap` step needed.
